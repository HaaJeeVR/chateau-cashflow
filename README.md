# Château Cashflow

Een pixel-art tycoon-spel in de browser: je runt een wijnwinkel en houdt je cashflow (en je bankier) tevreden.

## Spelen

- **Online:** via GitHub Pages (zie de link rechtsboven bij *About* / *Deployments*).
- **Lokaal:** open `index.html` in je browser. Geen installatie of build nodig.

## Structuur

| Map / bestand | Inhoud |
|---|---|
| `index.html` | Startpunt van het spel |
| `src/` | Spelcode (simulatie, rendering, UI, teksten) |
| `assets/` | Sprites, achtergronden, kaarten en de bijbehorende JS-manifests |
| `tools/` | Python-scripts om assets te bouwen en Node-tests/balans-scripts |
| `01_ONTWERP.md` … `06_ADVIESVRAGEN.md` | Ontwerp, art, bouwplan, besluiten en adviesvragen |

De grote bronafbeeldingen (`art_bronnen/`) staan bewust niet in de repo.
